# 设置窗口 (原生 Tk) 设计

日期: 2026-09-25 · 状态: 设计已与用户逐节确认, 待用户审阅本文档

## 1. 目标与范围

把托盘右键菜单里的所有设置搬进一个原生设置窗口; 托盘菜单只留状态和两个操作.

- 只做 Windows (用户决定不考虑跨平台), 可用 Win11 专有特性 (深色标题栏, 系统圆角).
- 技术: Tk + PIL (客户端 exe 已打包; 不引入新第三方库, 不重新打包 exe). 否决的方案: Edge 网页窗口 (用户不想多一个 Edge 进程); 重新打包内嵌 WebView (打包流程未验证, 风险大).
- 不在范围: 在线流式识别接入术语表 (单独待办); 豆包接入 (等用户凭据).

## 2. 托盘菜单

```
识别: 千问 qwen3-asr-flash (在线)    <- 状态, 点击无动作
二次整理: 关
今日花费: ¥0.12
────
设置…                               <- 默认项: 左键单击托盘图标也打开
退出
```

- 去掉「重启」(用户从未用过) 和现有全部设置子菜单.
- 状态文字每次重建菜单时重新计算 (沿用现有 refresh_menu, 每句识别后刷新).

## 3. 窗口

- 单实例: 已打开时再点「设置…」只把窗口提到最前.
- 约 880 x 600, 可调大小; 左侧导航, 右侧内容; Win11 深色 / 浅色标题栏跟随配色.
- 配色跟随当前胶囊主题: 墨玉 / 极光 / 微点 / 光环 / 经典深色 -> 深色; 霜白 / 经典浅色 -> 浅色.
  颜色直接取 capsule_themes 各主题的 BG / FG / 强调色, 换主题后窗口即时换色.
- 字体: 界面 Microsoft YaHei UI; 编辑框 Cascadia Mono (没有则 Consolas).
- 除词库外, 所有选项点了即生效, 无「保存」按钮 (与现托盘行为一致).

## 4. 分页 (按用户指定顺序)

| # | 分页 | 内容 |
|---|---|---|
| 1 | 统计 | 今日 / 本月 / 累计: 句数, 音频分钟, 花费; 按模型分行 (含本地模型, 费用 0); 二次整理 token 用量 (上行 / 下行 / 缓存命中率); 最近 14 天每日花费柱状图 |
| 2 | 外观 | 每个胶囊主题一张真实预览图 (用 capsule_themes.Capsule 渲染录音态一帧; 经典样式用其配色画同尺寸药丸), 点选即用 |
| 3 | 词库 | 术语表 / 热词 / 替换规则 三个标签页; 等宽编辑框; 有未保存改动时标题带 ●; Ctrl+S 或「保存」原子写回 (临时文件 + 替换). 无需重启: 术语表按文件修改时间缓存, 下一句即读新内容 (core/tools/terms.py); 热词 / 规则由现有 watchdog 文件监视自动重载 (core/client/hotword/manager.py) |
| 4 | 识别引擎 | 顶部 本地 / 云端 二选一. 本地: SenseVoice / Fun-ASR-Nano / Qwen3-ASR 单选 (未安装置灰, 切换会重启服务端约 5-15s, 页面提示). 云端: 「流式 · 边说边出字」「非流式 · 松开后识别」两组, 每项写单价与大致速度, 缺 key 标红; 并注明兜底用的本地模型. 页底小节「识别后整理」: 关 / DeepSeek / MiniMax / MiMo + 结构化开关 |
| 5 | 麦克风 | 录音设备单选 (设为 Windows 默认); 增益档位; 「开始校准」按钮 |
| 6 | 关于 | 版本号 (config __version__); fork 与上游 GitHub 地址 (可点开); 打开安装目录 / 日志目录; 各 API key 是否已配置 (只显示有无, 不显示内容) |

## 5. 代码结构

新目录 `core/client/settings/`, 每个文件一个职责:

| 文件 | 职责 |
|---|---|
| `window.py` | 单实例窗口, 导航, 分页切换, 按主题换色; 对外只暴露 `open_settings(app)` |
| `palette.py` | 由当前胶囊主题得出窗口配色 (bg / surface / fg / 次要文字 / 强调 / 描边) |
| `widgets.py` | 自绘控件: 单选卡片, 开关, 分段选择, 按钮, 统计卡片, 柱状图 (Canvas) |
| `pages/*.py` | 六个分页, 各自 `build(parent, ctx)` |
| `actions.py` | 从 tray_manager 抽出的操作 (切引擎 / 切服务商 / 结构化 / 切主题 / 切本地模型 / 麦克风 / 校准 / 读写词库), 托盘与窗口共用 |
| `stats.py` | 汇总 asr_usage.json + polish_usage.json 成页面要的数据 (纯函数) |

- 线程: 窗口挂在 ToastManagerThread 的 Tk 根窗口下. 在 ToastMessageManager 增加 `call_soon(fn)` (放进队列, 由 Tk 线程执行), 托盘回调经它打开窗口; 其他线程不直接碰 Tk.
- 本地识别用量: 客户端最终结果来自本地 (无在线结果) 时记 `asr_usage.add('local:<模型>', None, 秒数)`, 价格 0, 统计页据此显示本地句数与时长.
- tray_manager.py 大幅瘦身: 只剩状态行 + 设置 + 退出, 原有子菜单构造函数删除或迁入 actions.py.

## 6. 错误处理

- 窗口或任何分页出错只记日志, 在该分页显示错误文字, 不影响语音输入.
- 词库写入失败: 编辑框保留内容, 弹出失败原因; 写入只允许三个固定文件名.
- 切本地模型 / 校准等耗时操作: 按钮置为处理中, 完成后恢复, 不阻塞 Tk 线程 (后台线程 + call_soon 回写).

## 7. 测试

- `tests/test_settings_stats.py`: stats 汇总 (按模型 / 按天 / 14 天序列 / 缺文件).
- `tests/test_settings_actions.py`: 词库原子写 + 文件名白名单; 各设置写入 Config 与 user_state.
- 视觉: 离线把每个分页渲染到窗口后截图 (PIL ImageGrab), 逐页检查; 部署后用户实际点一遍.
